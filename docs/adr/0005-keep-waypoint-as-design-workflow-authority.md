# Keep Waypoint as the design workflow authority

Impeccable Design Actions are expressed as structured Design Intent on ordinary Annotations, but Waypoint continues to own Queue delivery, lifecycle, Work Notices, Resolution Records, Variant Sets, recorded Scaffold references, and Finalization decisions. Coding agents execute the corresponding source edits and reconcile temporary Scaffold after Keep or Cancel. We chose this over embedding Impeccable Live's separate polling and preview protocol so the integration can use Impeccable's design discipline without creating competing authorities for work state, outcomes, or candidate cleanup decisions.
