# Keep Waypoint as the design workflow authority

Impeccable Design Actions are expressed as structured Design Intent on ordinary Annotations, but Waypoint continues to own Queue delivery, lifecycle, Work Notices, Resolution Records, Variant Sets, Scaffold, and Finalization. We chose this over embedding Impeccable Live's separate polling and preview protocol so the integration can use Impeccable's design discipline without creating competing authorities for work state, outcomes, or candidate cleanup.
