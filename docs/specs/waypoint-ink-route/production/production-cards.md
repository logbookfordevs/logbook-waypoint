# Waypoint Ink Route — Route A Production Cards

**Status:** Replacement tracer shot and awaiting director screening. Runtime ownership is evidence, not final architecture.

## Segment card — Hero to first Annotation

- **Global span:** Useful hero → held-breath clear → ink impact → route travel → first Annotation.
- **Narrative change:** A precise user action causes the chart world to come into existence and resolves into retained product evidence.
- **Authority:** One normalized scroll progress remains authoritative. Programmatic activation, native scroll, reverse, and direct hash entry converge on it.
- **Owned resources:** GPU canvas, desktop/mobile chart textures, ink density texture, route shader, procedural audio bus, live Annotation overlay.
- **enter:** Decode and upload the three source textures; compile the shader; prepare audio only after focus or contact.
- **scrub:** Derive hero exit, impact, continuous curve distance, world corridor reveal, camera/parallax, Annotation opacity, and route-velocity sound from the same progress.
- **teardown:** Remove listeners, cancel animation frames, stop and close audio, delete textures/buffer/program, and release context-owned resources.
- **Interruption:** Reverse reconstructs picture silently; visibility loss suspends sound; resize remeasures origin/target and resizes the capped drawing buffer; direct `#annotation` enters the completed stable state.
- **Reduced motion:** Jump to one authored static destination; no timed entrance; focus the journey heading; sound remains paused.
- **Renderer failure:** Replace the canvas with the matching authored static chart while retaining live DOM copy, controls, focus, and product meaning.

## Effect card — Material ink and world propagation

- **Narrative job:** Transform the remembered CTA origin into a physical mark whose travel authors the environment.
- **Mechanism:** A WebGL 1 full-screen compositor samples an authored world plate and a luminance-derived ink-density texture. A continuous cubic-curve distance field drives the wet route and corridor reveal; interpolated value noise varies absorption, dry-brush loss, stain, and edge breakup.
- **Render order:** Paper field → opening-world evidence → route-led world reveal → shallow edge parallax → ink-density impact → live route/stain → grade → crisp DOM Annotation evidence and controls.
- **Warm path:** Compile once, decode/upload all tracer textures, then draw before impact is reachable. The current study loads both aspect compositions to keep live resize deterministic.
- **Fidelity:** Capable tier uses the GPU compositor; reduced motion uses the completed static composition; renderer failure uses the authored static plate; semantic content remains in DOM at every tier.
- **Mobile precision:** Fragment shader requests `highp`; drawing-buffer scale is capped at `1.35` below 720 px and `1.65` otherwise. Real Adreno/Mali hardware remains unverified.
- **Cleanup owner:** `InkRouteRenderer.dispose()`.
- **First-use trace:** Desktop `1440 × 900` observed `3.0 ms` maximum route work and `0.7 ms` at impact in the final recorded session; mobile `375 × 812` observed `1.3 ms` maximum and `0.5 ms` at impact. Browser/video-capture scheduling produced several non-route frame gaps and is not a substitute for a DevTools GPU trace.

## Runtime ownership finding

The custom WebGL compositor reached the bounded picture with one program, two sampler inputs per frame, no React render-loop state, and deterministic teardown. That is positive evidence that Route A does not require full 3D. It is not yet a final choice against PixiJS or Three.js: production expansion, multiple independently owned plates, ping-pong simulation, richer post-processing, or an asset-loading graph may still make an engine the deeper module.

No renderer package was installed. Dependency selection remains unapproved until the director accepts the visual direction and the next production frontier makes the owner decision real.
