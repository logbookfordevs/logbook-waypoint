# Waypoint Ink Route — Motion Specification

**Status:** Implemented production cut in the disposable worktree.

## Authority

One normalized native-scroll projection owns the image. The homepage does not run a second cinematic clock. Manual wheel, trackpad, touch, keyboard scroll, programmatic journey activation, reverse travel, and direct hash entry all reconstruct from document position.

React state is restricted to stable semantics: active chapter, explicit sound intent, and whether the journey gate was activated. Continuous progress, velocity, path projection, scene visibility, and audio gain remain outside React rendering.

## Entrance edit

| Prologue progress | Picture | Purpose |
| --- | --- | --- |
| `0.00–0.18` | Complete useful hero | Orient and preserve immediate product access. |
| `0.18–0.46` | Hero, masthead, and Thelu clear | Release the practical frame as one authored layer. |
| `0.46–0.60` | Uninterrupted Driftwood Paper | Hold a brief visual breath; no ornamental substitution. |
| `0.60–0.78` | Black ink impact and capillary marks | Make the visitor's action visibly causal. |
| `0.78–1.00` | First route segment appears | Turn impact into forward travel. |

The CTA uses tactile CSS contact feedback. After activation, the browser scrolls to the journey using native smooth scrolling and moves keyboard focus to the journey region after the entrance settles. Reduced motion uses an immediate scroll and focus handoff.

## Journey edit

The journey occupies four equal scroll territories:

1. Annotation — precise Target and retained brief.
2. Queue — local lifecycle and evidence retention.
3. Agent — MCP handoff, Claim, and implementation.
4. Resolution — returned evidence and human judgment.

Each scene derives visibility from local chapter progress. Noninitial scenes enter over the first 14% of their territory; nonfinal scenes release over the last 18%. The first and last plates remain stable at their outer boundaries. The central route advances from 8% at the end of the prologue to 100% at the end of Resolution.

The Agent plate is the only dark-ocean interruption. It changes atmosphere at the handoff point without changing type roles, route logic, or navigation ownership.

## Scroll and interruption

- A passive scroll listener schedules at most one animation frame.
- Each frame reads the prologue and journey geometry once, then writes bounded custom properties, SVG stroke/tracer attributes, and audio gain.
- Reverse scroll reconstructs the picture deterministically. Ink impact does not replay backward and scratch is silent for negative velocity.
- Resize recomputes geometry from live element bounds. No remembered desktop coordinates are reused.
- Hidden documents ramp scratch to zero; visible documents reconstruct from current scroll position.
- Chapter React state updates only when the discrete chapter changes.

## Sound

Sound is opt-in and unlocked only by **See the journey** or the visible sound control. A procedural Web Audio bus provides:

- a short filtered triangle impact synchronized to the first ink threshold;
- a band-limited noise texture whose gain follows positive route velocity;
- a fast release when scrolling stops;
- a persistent mute control in the hero and journey chrome.

No narration, ambient bed, music, external audio file, or sound-only meaning ships in this cut. Recorded nib-on-paper foley remains an optional replacement if human listening finds the procedural texture insufficiently material.

## Responsive blocking

- Desktop composes copy and Thelu as two subjects, then pairs each chapter's narrative with live product evidence.
- At 390 px, the hero becomes a deliberate vertical poster and each chapter becomes a full-screen map plate. Product evidence is reblocked below copy rather than horizontally clipped or scaled down.
- Short desktop heights compact vertical rhythm without removing the CTA.
- The route remains background geography and never becomes a gesture-only navigation surface.

## Reduced motion

With `prefers-reduced-motion: reduce`:

- the hero remains a stable useful frame;
- smooth scrolling, hero clearing, ink impact, route drawing, scene crossfades, radar animation, and route audio are removed;
- all four destinations render in semantic document order as static plates;
- journey activation scrolls directly and moves focus without enabling the audio context;
- dynamic chapter and sound chrome is hidden because it would imply a timeline that is not running.
