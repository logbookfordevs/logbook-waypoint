## Direction

A written annotation detaches from the margin and crosses into a Deep Ocean Queue. The same text and target survive the edit. The visitor makes the handoff; no passive autoplay substitutes for agency.

## Shot and motion spine

1. Opening: static editorial spread with a useful Get Waypoint documentation action. The specimen is already visible.
2. Annotation: visitor selects the sample heading. Heading and sheet reframe; geometric rust selection brackets draw. Fresh input writes/pins the note.
3. Retained note: paper slip carries actual visitor text and target metadata; visitor triggers Queue transfer.
4. Queue threshold: slip moves into ocean docket; the same note and selector remain visible. Next: a coding agent can inspect and claim the work. No agent execution is simulated.

One semantic stage owns all layers. Finite, interruptible Motion transitions; no background loop, scroll capture, camera timer, or renderer. Reduced motion uses zero-duration transitions. Readable mode presents the complete explanation. Sound is opt-in existing narration, independently mutable; it conveys no exclusive meaning. Replay clears only demo state. Input supports keyboard and touch through native controls. No backend writes.
