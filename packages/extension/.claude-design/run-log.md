# PT-301 prototype run log

- Question: How should an optional Impeccable workflow and exactly one Design Action appear inside Waypoint's existing 340px Annotation editor without competing with freeform intent or Request Variants?
- Canonical action catalog: Bolder, Quieter, Distill, Polish, Typeset, Colorize, Layout, Animate, Delight, Overdrive.
- Round two: A Wrapped catalog, B Compact chooser, C Status plus matrix, D Status plus list, E Hybrid summary. All derive from the explicit opt-in boundary in A and the two-stage state language in E.
- State language: Impeccable enabled without a named action is `On - Freeform`. Once an action is selected, `Freeform` disappears and the named action becomes the status.
- Scope: Throwaway, in-memory UI only. No production contracts or editor implementation changed.
